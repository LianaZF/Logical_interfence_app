# Программа логического вывода

Приложение использует интервальные нечёткие правила второго типа, сформированные основной программой.

## Запуск

```powershell
python main.py
```

## Функции принадлежности

Окно функций принадлежности использует те же правила отображения, что и первая
программа: легенда над графиком, единые шрифты и подписи осей, опорные точки
верхней и нижней ФП. Щелчок по элементу легенды скрывает или показывает линию,
колесо мыши меняет масштаб, перетаскивание левой кнопкой перемещает график, а
двойной щелчок возвращает исходный вид. При наведении на опорную точку выводятся
ее координаты.

Для проверки интерфейса на демонстрационных данных:

```powershell
python main.py --rules examples/demo.nfrules --data examples/demo_objects.csv
```

Готовая сборка находится в `bin/LogicalInference.exe`. Это один файл со
встроенными Python, библиотеками и темами; папка `_internal` не нужна.

Повторная сборка выполняется из каталога проекта командой:

Из корня общего репозитория:

```powershell
.\tools\build.ps1 -App inference
```

Обе программы используют общее окружение `.venv`. Его установка и проверка
описаны в `../README.md`.

1. В основной программе сформируйте правила второго типа.
2. В меню `Правила классификации 2-го типа -> Сохранить` сохраните базу `.nfrules`.
   В неё входят термы, классы, интервалы CF, параметры верхних и нижних ФП и кодирование признаков.
3. В программе логического вывода загрузите этот файл как базу правил.
4. Выберите пакетный режим и файл объектов либо интерактивный ручной ввод.

Пакетный файл должен содержать строку заголовков. Названия входных признаков должны совпадать с базой правил. Столбец фактического класса необязателен.
